        1. symantic element introduce in HTML5
        2. new tags , new attribute and new input type are introduce
           eg.new attribute= minlength , maxlength, pattern,min , max
           new inputtypes = email , tel, password, number, date, time , week
           new tag : em, strong, ins, abbr, tbody , thead,address.

        3. multimedia elements introduce
                support audio and video
        4. API introduce in HTML5
                - it is a small program which is already present which we can use directly 
                -1 Geolocation: it return user current location
                                -to use this api in your device GPS must be present.
                -2 Drag and Drop: it allow user to grab an object from one location and drag to another location (like cut past)
                -3 Web-Worker: it small js code which execute in the backend of browser without affecting its current execution
                -4 WebStorage: it used to store user data on browser 
                         there are two type of WebStorage
                         1 local storage :
                                        -used to store user data permanently.
                         2 session storage:
                                        -used to store user data for limited time.
                -5 SSE(server sent event):
                                -allow user to get automatic update from the server.
